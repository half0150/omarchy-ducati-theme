# Ducati Panigale

A dark Omarchy theme inspired by the Ducati Panigale V4 sportbike. Warm red accent on near-black backgrounds, with wallpapers from a moody studio session.

## Preview

Add screenshots here once the theme is running on your machine:

- `preview.png` (1800x1012) — themed desktop
- `preview-unlock.png` (1920x1080) — lock screen

## Install

```bash
git clone https://github.com/half0150/omarchy-ducati-theme.git ~/.config/omarchy/themes/ducati-panigale
omarchy-theme-set ducati-panigale
```

To update later:

```bash
cd ~/.config/omarchy/themes/ducati-panigale
git pull
omarchy-theme-set ducati-panigale
```
